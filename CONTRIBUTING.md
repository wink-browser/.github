# Contributing

Wink's code, issues and pull requests live in [wink-browser/wink](https://github.com/wink-browser/wink). Start with its [CONTRIBUTING.md](https://github.com/wink-browser/wink/blob/main/CONTRIBUTING.md), which covers the build, the tests and the sign-off.

Problems with a download belong there too: [open an issue](https://github.com/wink-browser/wink/issues/new/choose).
