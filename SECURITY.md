# Security

Please report security problems in any Wink repository privately: **[open a security advisory](https://github.com/wink-browser/wink/security/advisories/new)** on the main repository. Only the maintainers can see it. Please don't open a public issue or pull request for a vulnerability.

What to include, what we most want to hear about, and which versions get fixes: [wink-browser/wink › SECURITY.md](https://github.com/wink-browser/wink/blob/main/SECURITY.md).
